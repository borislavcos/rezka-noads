# Rezka без рекламы - модуль для TizenBrew

Режет пре-роллы, попапы и баннеры на rezka и добавляет нормальное управление пультом.
Под Samsung QE75Q60A (Tizen 6.0), должно работать на любом Samsung с 2017 года.

## Что делает

- **Пре-ролл**: запросы к VAST/VPAID и рекламным сетям получают пустой ответ, плеер думает, что рекламы нет, и сразу запускает фильм. Плюс из конфига плеера (Playerjs) вырезаются `preroll / midroll / postroll / pauseroll / vast`.
- **Страховка**: если реклама всё равно заиграла, видео глушится и проматывается в конец, кнопка "Пропустить" нажимается сама.
- **Попапы**: `window.open` и ссылки "в новой вкладке" на чужие домены блокируются.
- **Баннеры**: прячутся типовые рекламные блоки.
- **Пульт** (только на ТВ):

| Кнопка | На сайте | В плеере (полный экран) |
|---|---|---|
| Стрелки | переход между ссылками, озвучками, сериями | ← → перемотка 10 сек, ↑ ↓ показать время |
| OK | нажать / на плеере - запустить и развернуть | пауза / play |
| Back | назад по истории | выйти из полного экрана |
| Play/Pause | пауза / play | пауза / play |
| Каналы ^ / v | листать страницу целым экраном | перемотка 60 сек вперёд / назад |
| FF / REW (если есть на пульте) | перемотка 60 сек | перемотка 60 сек |

Чтобы набрать `12345` для Developer mode на пульте SolarCell: нажми кнопку **123** (с цветными точками), на экране появится цифровая панель, цифры выбираются кольцом и центральной кнопкой.

## Установка

### 1. Залить на GitHub
Создай **публичный** репозиторий (например `rezka-noads`) и положи в корень `package.json` и `userScript.js`.
В `package.json` поменяй `websiteURL` на зеркало, которое у тебя открывается.

### 2. Поставить TizenBrew на телик
1. На ТВ: **Apps** -> на пульте набрать `12345` -> **Developer mode: On** -> в **Host PC IP** вписать IP своего компа -> OK -> перезагрузить ТВ (держать кнопку питания до логотипа).
2. На компе скачать **TizenBrew Installer** для своей ОС: https://github.com/reisxd/TizenBrewInstaller/releases/latest
3. Запустить и нажать **Install TizenBrew**. На Tizen 6 сертификат Samsung не нужен (он нужен только с Tizen 7).

### 3. Добавить модуль
TizenBrew -> **Module Manager** -> **Добавить модуль с GitHub** -> ввести `твой_ник/rezka-noads`.
В списке появится **Rezka без рекламы**, запускаешь его.

### Обновление
После правок на GitHub CDN (jsDelivr) может отдавать старую версию. Сбросить кэш - открыть в браузере:
```
https://purge.jsdelivr.net/gh/твой_ник/rezka-noads/userScript.js
https://purge.jsdelivr.net/gh/твой_ник/rezka-noads/package.json
```
и перезапустить TizenBrew на ТВ.

## Отладка на компе (рекомендую начать с этого)

1. Поставь в Chrome расширение **Tampermonkey** -> "Создать скрипт" -> вставь весь `userScript.js` -> сохрани.
2. В начале скрипта поставь `DEBUG: true`.
3. Открой фильм на резке, F12 -> Console. Всё заблокированное пишется как `[rezka-noads] BLOCK ...`, на экране всплывает счётчик.

**Если пре-ролл всё равно идёт**: F12 -> Network, запусти фильм, смотри, откуда грузится реклама (фильтр `vast`, `xml`, `ad`). Домен добавь в `AD_HOSTS`, характерный кусок адреса - в `AD_URL_PATTERNS`.

**Если сломался плеер**: включи `DEBUG`, посмотри, что заблокировано прямо перед поломкой, и убери слишком широкий паттерн.

Навигацию пультом на компе можно проверить, поставив `FORCE_NAV: true`.

## В паре с DNS
Для надёжности на ТВ можно ещё прописать DNS AdGuard (`94.140.14.14` / `94.140.15.15`): он отрежет рекламные домены на уровне сети, а модуль доберёт то, что идёт через плеер.
